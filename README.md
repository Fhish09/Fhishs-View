# Fhish's View

**Your Windows. Reimagined.**

A premium desktop overlay for Windows 10/11, inspired by Apple's Dynamic Island — rebuilt in **Python + PyQt6**.

## Features

- Floating glass Dynamic Island at the top center of the screen
- Fluid compact → medium → expanded states with smooth animations
- Music control panel (UI ready)
- Search panel (UI ready)
- System controls panel (Wi-Fi, volume, focus)
- Deep black glassmorphism with soft shadow and glow
- Drag to reposition · Escape to collapse

## Requirements

- Python 3.10+
- Windows 10 or 11

## Install & Run

```bash
pip install -r requirements.txt
python main.py
```

## Controls

- **Click** the compact island → expands to medium menu
- **Music / Search / System** chips → open that panel
- **✕** or **Esc** → collapse back
- **Drag** the island to move it
